# Upside

**Upside** is a 2D arcade-style game developed in Unity. The goal is simple: control a square, move up and down, and dodge incoming obstacles for as long as possible. The longer you survive, the higher your score gets.

This project was built to practice Unity game development and improve my understanding of player movement, obstacle spawning, collision detection, and scoring systems.

##  Gameplay

- Control a square character in a 2D environment
- Move the square up and down to avoid obstacles
- Use the mouse to control the player's movement
- Dodge incoming obstacles
- Survive as long as possible
- Earn a higher score by surviving longer

##  Built With

- Unity
- C#

##  Controls

-Mouse Click 
-Move the square up/down 

##  Objective

Avoid the incoming obstacles and survive for as long as possible.

The longer you survive, the higher your score!

## Why I Built This

I wanted to create a simple and addictive arcade-style game while improving my Unity development skills.

This project helped me understand:

- Player input and movement
- Obstacle spawning
- Collision detection
- Score systems
- Game over logic
- Basic 2D game mechanics
