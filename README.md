Upside

Upside is a 2D arcade-style game developed in Unity. The goal is simple: control a square, move up and down, and dodge incoming obstacles for as long as possible. The longer you survive, the higher your score gets. This project was built to practice Unity game development and improve my understanding of player movement, obstacle spawning, collision detection, and scoring systems.

Gameplay
Control a square character in a 2D environment
Move the square up and down to avoid obstacles
Click the mouse to move the square up or down
Dodge incoming obstacles and survive as long as possible
Earn a higher score by surviving longer
Built With
Unity
C#
Controls
Mouse Click – Move the square up or down
Mouse Movement/Clicking – Control the player's vertical movement
Why I Built This

I wanted to create a simple and addictive arcade-style game while improving my Unity development skills. This project helped me understand player input, vertical movement, obstacle spawning, collision detection, and score systems while creating a fast-paced gameplay experience.
